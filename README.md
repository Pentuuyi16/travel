# ДагТур — бэкенд (Node.js + SQLite)

Бэкенд для сайта турфирмы: регистрация/вход, анкеты гидов, админ-панель
с приёмом/отклонением заявок, профиль (в т.ч. «Профиль гида»), красивые
баннеры-уведомления о решении по заявке.

## Запуск

```bash
npm install        # поставить зависимости
node server.js     # запустить сервер
```

Сайт:        http://localhost:3000/main.html
Админ-панель: http://localhost:3000/admin.html

База данных (`dagtur.db`) и папка `uploads/avatars/` создаются автоматически
при первом запуске.

## Администратор по умолчанию

При первом запуске создаётся аккаунт админа:

```
email:  admin@dagtur.ru
пароль: admin123
```

**Смените пароль** после первого входа (в профиле) — или поменяйте логин/пароль
в `db.js` (константы `ADMIN_EMAIL`, `ADMIN_PASSWORD`) до первого запуска.

## Как это работает

1. Пользователь регистрируется на сайте (кнопка «регистрация»/«вход» в шапке).
2. Заполняет анкету на странице **гидам** (`gidy.html`) и отправляет.
   Если он не вошёл — сайт предложит зарегистрироваться.
3. Заявка появляется в **админ-панели** во вкладке «Новые».
4. Админ нажимает **«Принять в гиды»** или **«Отклонить»**:
   - **Принять** → роль пользователя меняется на `guide`, ему создаётся
     уведомление. При следующем заходе на сайт он увидит красивый
     синий баннер-поздравление; в меню «Профиль» превращается в
     **«Профиль гида»**, где можно сменить аватар, имя, email, пароль.
   - **Отклонить** → пользователю показывается баннер с вежливым отказом,
     роль остаётся `user`.

Уведомления показываются один раз (помечаются прочитанными при закрытии).

## Технологии

- **Express** — веб-сервер и API.
- **node:sqlite** — встроенный в Node.js 22+ модуль SQLite (нативная сборка
  не нужна, поэтому `better-sqlite3` не используется).
- **bcryptjs** — хеширование паролей.
- **jsonwebtoken** + **cookie-parser** — сессии в httpOnly-куке.
- **multer** — загрузка аватарок.

## Структура

```
server.js          API + раздача статики
db.js              схема БД, сид администратора
admin.html         админ-панель (вход + заявки)
profile.html       профиль пользователя / гида
gidy.html          лендинг гидов с анкетой (подключён к API)
js/auth.js         фронт: авторизация, меню, баннеры-уведомления
main.html, tours/  страницы сайта
css/, image/       стили и картинки
```

## Важно про авторизацию

Раньше вход был на **Firebase**. Для задачи (роли в своей БД, смена пароля,
админка) авторизация перенесена на собственный бэкенд — все пользователи
лежат в `dagtur.db`. Вход через Google убран (его можно вернуть отдельно).

## API (кратко)

| Метод | Путь | Назначение |
|------|------|-----------|
| POST | `/api/register` | регистрация |
| POST | `/api/login` | вход |
| POST | `/api/logout` | выход |
| GET  | `/api/me` | текущий пользователь |
| PUT  | `/api/profile` | сменить имя/email |
| PUT  | `/api/profile/password` | сменить пароль |
| POST | `/api/profile/avatar` | загрузить аватар |
| POST | `/api/guide/apply` | отправить анкету гида |
| GET  | `/api/guide/my-application` | статус своей анкеты |
| GET  | `/api/notifications` | непрочитанные баннеры |
| POST | `/api/notifications/:id/seen` | пометить прочитанным |
| GET  | `/api/admin/applications?status=` | заявки (admin) |
| POST | `/api/admin/applications/:id/accept` | принять (admin) |
| POST | `/api/admin/applications/:id/reject` | отклонить (admin) |
